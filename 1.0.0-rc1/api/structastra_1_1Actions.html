struct Actions

A record of all action functions for a reflected type.

Public Functions

inline constexpr Actions(TypeInfo (*reflect)(void*, bool), const std::string &(*typeName)(), std::size_t (*sizeOf)(), void (*construct)(void *p), void (*destroy)(void *p), void (*copy)(void*, const void*), void (*move)(void*, void*))

Create a new actions record.

Parameters:

  • reflect – Takes in a pointer to an object and a const-ness flag and returns the appropriate TypeInfo

  • typeName – Returns the name of the type

  • sizeOf – Returns the size of the type

  • construct – Invokes the constructor to create a new object of the type in the given pointer

  • destroy – Invokes the destructor to clean up the object given by the pointer

  • copy – Copies the object at the second pointer to the first pointer

  • move – Moves the object at the second pointer to the first pointer

constexpr Actions(const Actions &other) = default
constexpr Actions &operator=(const Actions &other) = default
