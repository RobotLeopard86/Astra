template<class T, std::size_t size>
class ConstexprMap

A tree-based map that works at compile-time.

The map is sorted and thus has O(log n) search time complexity, using separate pointers for keys and values; O(n^2) complexity on initial sort

Template Parameters:

  • T – The type of data to store

  • size – The size of the map
