class TypeInfo : public astra::Variant<Bool, Integer, Floating, String, Enum, Object, Array, List, Map, Pointer>

The sum type contains information about nature of stored value

Primitive for int, float, std::string and others Object for structs and classes Array List for arrays and containers with one generic parameter Map for associative container such as std::map Pointer for smart pointers
